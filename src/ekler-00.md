# Ekler

İzleyen bölümler, Rust yolculuğunuzda elinizin altında bulundurabileceğiniz başvuru kaynaklarını içerir: dilin anahtar kelimeleri, operatör ve sembol sözlüğü, türetilebilir (`derive`) standart kütüphane trait'leri, yararlı geliştirme araçları, Rust sürümleri (*editions*), kitabın çevirileri ve Rust'ın geliştirilme süreci ile *Nightly Rust*.
